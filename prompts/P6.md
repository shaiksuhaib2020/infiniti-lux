#### The Logotype Component — `InteractiveLogotype.jsx`

This is the centerpiece of the page. Every detail below matters for the effect to feel premium rather than gimmicky.

**Component structure:**

The logotype is built from three typographic layers stacked vertically, centered on both axes:

---

**Layer 1 — Brand wordmark (the interactive element):**

The text "Infiniti Luxe" is not rendered as a single text node. It is rendered as a `<span>` per character — 12 individual span elements, spaces included as non-interactive spacer spans. Each character span is `display: inline-block` (required for individual transform to work) and `position: relative`.

**Font:** `--font-display` (Cormorant Garamond), `108px` on desktop, `64px` on tablet, `48px` on mobile. Weight `300`. White. Letter-spacing `-0.03em`. Line-height `1`.

**On page load — entrance animation (GSAP):**

```
Each character animates from:
  opacity: 0
  y: 40px
  filter: blur(4px)

To:
  opacity: 1
  y: 0
  filter: blur(0px)

Duration: 0.7s per character
Ease: power3.out
Stagger: 0.04s per character, left to right
```

The blur-in combined with the rise creates a cinematic reveal — each letter materialises from soft to sharp. The stagger means the word arrives as a wave rather than all at once.

**On mouse move — magnetic character effect:**

After the entrance animation completes, the component attaches a `mousemove` listener to the wordmark container. On each mouse move:

1. Calculate cursor position relative to the container
2. For each character span, calculate the Euclidean distance between the cursor and the character's center point
3. If distance is within `90px` radius: apply a GSAP `to` on that character with a small x/y displacement pulling the character subtly toward the cursor
4. Displacement formula: `displacement = (1 - distance/90) * maxDisplacement` where `maxDisplacement = 10px`
5. If distance is beyond `90px`: GSAP `to` back to `x: 0, y: 0`
6. Duration for each individual character tween: `0.4s`, ease `power2.out`

**On mouse leave the container:** All characters return to `x: 0, y: 0` over `0.6s`, ease `power3.out`, staggered `0.02s` so the reset is also a subtle wave.

**Important implementation note:** The mousemove handler must use `requestAnimationFrame` throttling — do not fire GSAP tweens on every raw mousemove event. Throttle to `~60fps`. Without this the animation will be jittery.

**On mobile (touch devices):** The magnetic effect is disabled entirely — no touch event equivalent. The entrance animation plays as normal. Check `window.matchMedia('(hover: none)')` to detect touch-primary devices and skip the effect.

---

**Layer 2 — Tagline with animated gold underline:**

"Travel Beyond Boundaries."

**Appears 0.6s after the wordmark entrance begins** — it starts once the first characters of the wordmark are visible.

Font: `--font-body`, `16px`, white at 55% opacity, weight 400, letter-spacing `0.18em`. Centered. Margin-top `24px`.

**The animated underline:**

A `2px` horizontal line in `--color-gold` sits `8px` below the tagline text. It is not a text-decoration underline — it is a separate `div` with:
- `height: 2px`
- `background: --color-gold`
- `width: 0`
- Centered using `margin: 0 auto`

GSAP animates `width` from `0` to `140px` over `0.8s`, ease `power2.inOut`, beginning `0.3s` after the tagline fades in. The line draws left to right, beginning from center outward — achieved by setting `transformOrigin: 'left center'` and animating `scaleX` from `0` to `1` on a full-width container, then revealing it via that container's `overflow: hidden`.

---

**Layer 3 — Scroll invitation:**

Positioned at the absolute bottom-center of the section. `32px` above the bottom edge.

Content: A thin vertical line (`1px solid rgba(255,255,255,0.20)`, height `48px`) above a small text label: "Get in touch" — `--font-body`, 11px, white at 40% opacity, letter-spacing 0.1em.

GSAP animation: The line's height animates from `0` to `48px` on a loop — expanding downward, then a brief pause, then resetting. Duration `1.8s`, ease `power1.inOut`, repeat `-1` (infinite), `yoyo: false`. This creates a subtle "breathing" line that suggests downward movement without being an animated arrow.

**On click of this element:** Smooth-scroll to Section 2.

---

**`prefers-reduced-motion` handling for this section:**

If reduced motion is active:
- Skip the entrance stagger — all characters appear at `opacity: 1` immediately
- Skip the magnetic effect entirely
- Skip the scroll line animation — display the line statically
- Keep the gold underline but make it appear instantly rather than animating

**Form validation — client-side, before any submission attempt:**

Required fields: Name, WhatsApp Number, Email, at least one Service checkbox.

Validation fires on submit click — not on blur. Validate each required field, collect all errors, display all simultaneously rather than one at a time. This avoids making the user fix errors in a sequence.

Email format validation: simple regex check.

WhatsApp number: validate that the field is not empty and contains at least 7 digits. Do not over-validate phone number format — international formats vary widely.

## PART 4 — QUERY PARAM HANDLING

The Contact page receives `?service=` query params from every service page CTA (e.g., `/contact?service=visa`, `/contact?service=flights`).

The agent reads this param using Next.js `useSearchParams()` in a client component and uses the value to:

1. Pre-select the matching service checkbox in the form on mount
2. Update the `document.title` subtly: if `?service=visa` then the page `<h1>` area uses the same "Let's Plan Your Journey" heading but the form card shows a small pre-selected indicator above the checkboxes: a gold-tinted tag reading "Visa enquiry pre-selected" — `--font-body`, 12px, `--color-gold`, with a small Lucide `X` to dismiss it

The query param handling is wrapped in a `Suspense` boundary as required by Next.js App Router.

**Accepted `service` param values and their checkbox mappings:**

| Query param value | Checkbox pre-selected |
|---|---|
| `visa` | Visa |
| `flights` | Flight |
| `hotels` | Hotel |
| `holidays` | Holiday |
| `tours` | Tour |
| `honeymoons` | Honeymoon |
| `corporate` | Corporate |
| `cruises` | Cruise |
