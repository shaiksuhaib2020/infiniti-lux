## PART A — WHY THE ORIGINAL PALETTE WAS WRONG

The original palette (`#FEFFFC` parchment, `#41A1CF` signal blue) reads as a generic SaaS or fintech product. Signal blue is used by booking platforms everywhere — Booking.com, Expedia, Skyscanner. It communicates utility, not luxury. Parchment backgrounds are currently the most common AI-generated design tell.

A premium Dubai-based travel brand should feel closer to **Singapore Airlines, Regent Seven Seas, Aman Resorts** — brands that use a single rich dark anchor color, a warm metallic accent, and disciplined white space. The palette below is built around that logic.

## PART B — NEW COLOR SYSTEM

### The Logic

| Axis | Decision | Why |
|---|---|---|
| Background | Clean white, not warm cream | Cream reads as AI default right now; pure white reads modern and precise |
| Dark anchor | Deep abyss navy | Evokes night flights, ocean depth, the Dubai skyline at midnight — emotionally connected to travel |
| Accent | Champagne gold | Every genuine luxury travel brand (Emirates, Regent, Four Seasons) uses this exact axis — warm metallic, never yellow |
| No secondary accent | One accent only | The original cerulean as a second accent diluted the premium feel; one gold governs everything |

### The Palette

| Role | Token Name | Hex | Usage |
|---|---|---|---|
| Page background | `--color-white` | `#FFFFFF` | All light section backgrounds |
| Subtle surface | `--color-ice` | `#F5F7FA` | Alternating section backgrounds, form fields |
| Primary dark | `--color-abyss` | `#07111C` | Hero overlay base, navbar, footer, dark CTA sections |
| Secondary dark | `--color-deep-navy` | `#0D2035` | Cards on dark surfaces, dark section variants |
| Heading text | `--color-ink` | `#0E1824` | All major headings on white backgrounds |
| Body text | `--color-slate` | `#374151` | All body copy |
| Muted text | `--color-stone` | `#6B7280` | Captions, labels, metadata |
| Light border | `--color-border` | `#E5E7EB` | Cards, inputs, dividers on white |
| Dark border | `--color-border-dark` | `#1A3250` | Dividers on dark sections |
| Primary accent | `--color-gold` | `#C5973A` | All interactive elements, highlights, hover states |
| Gold hover state | `--color-gold-light` | `#DDB96A` | Hover glow, subtle gold tints |

### Color Rules for the Agent

- `--color-gold` is the **only accent** in the system. Remove all uses of the original signal blue `#41A1CF`.
- Dark sections (`--color-abyss` backgrounds) use white text at varying opacity levels: headings at 95%, body at 75%, muted at 50%.
- Gold is used for: interactive CTAs, hover text color inside PillNav, icon accents, section highlight labels, active nav states.
- Gold is **not** used for: body text, large blocks of color, card backgrounds, section fills.
- WhatsApp green appears only on WhatsApp-specific buttons. Never mix it with gold or use it decoratively.

## PART C — TYPOGRAPHY UPGRADE

### Replace Fraunces with Cormorant Garamond

The original spec called for Fraunces. Fraunces is a good font but it reads "independent creative brand." For a genuinely premium global travel company, **Cormorant Garamond** is the correct choice.

Cormorant Garamond is used by high-fashion houses, luxury hotel groups, and premium editorial publications. Its thin strokes and refined counters at weight 300–400 are genuinely expensive-feeling in a way that Fraunces is not. It is available on Google Fonts at no cost.

**Updated Google Fonts import (replace the Fraunces import entirely):**
- `Cormorant Garamond`: weights 300, 400, 500, 600 — italic variants included — `display=swap`
- `Inter`: weights 400, 500, 600 — `display=swap`

**Updated font tokens:**

```
--font-display: 'Cormorant Garamond', serif;
--font-body: 'Inter', sans-serif;
```

**Updated sizing notes for Cormorant Garamond:**
Because Cormorant Garamond has thinner strokes than Fraunces, the agent should scale sizes **slightly up** to maintain visual weight. Recommended adjustments:

| Role | Original spec | Updated for Cormorant |
|---|---|---|
| Hero headline | 64px | 72px, weight 300 |
| Major section heading | 48px | 52px, weight 400 |
| Section heading | 40px | 44px, weight 400 |
| Card title | 22px | 24px, weight 400 |
| Small display | 27px | 30px, weight 400 |

**Letter spacing for Cormorant Garamond:** Use `-0.02em` on large display sizes. At small sizes (under 24px), use `0` — Cormorant's thin strokes read poorly with negative tracking at small sizes.

## PART F — PILLNAV INTEGRATION BRIEF

### What the Agent Must Understand First

The PillNav from React Bits is built for React Router. The project uses **Next.js App Router**. The agent must perform three surgical adaptations before anything else:

1. Replace `import { Link } from 'react-router-dom'` with `import Link from 'next/link'`
2. Replace every `<Link to={href}>` with `<Link href={href}>`
3. Remove the `isRouterLink` helper function — in Next.js, all internal paths are router links. Use a simple check: `const isExternal = href.startsWith('http') || href.startsWith('mailto:') || href.startsWith('tel:')`. Internal links use `<Link>`, external links use `<a target="_blank" rel="noopener noreferrer">`.

### File Placement

```
/components/layout/
  PillNav.jsx         ← Adapted source (not the original)
  PillNav.css         ← Original CSS + overrides below
  Navbar.jsx          ← Wrapper that configures and renders PillNav
```

### Color Configuration for Infiniti Luxe

Map the new token system to PillNav props. Because `baseColor` in PillNav drives both the nav background and the hover circle color, the agent needs to understand what each prop actually does in the animation:

- The **hover circle** that expands on each pill item uses `baseColor` as its fill
- The **text inside the circle** uses `hoveredPillTextColor`
- The **normal nav item text** uses `pillTextColor`
- The **nav items container** background uses `baseColor`

For Infiniti Luxe, the desired hover effect is: **a deep navy circle expands, text color switches from white to gold**. This creates an elegant, restrained animation — no color explosion, just a premium state change.

**PillNav props to pass:**

```
baseColor       = "#07111C"          (--color-abyss: nav container bg + hover circle)
pillColor       = "rgba(255,255,255,0.08)"   (subtle glass-like pill containers)
pillTextColor   = "rgba(255,255,255,0.85)"   (default ivory-white text)
hoveredPillTextColor = "#C5973A"     (gold text revealed on hover)
ease            = "power3.out"
initialLoadAnimation = true
```

### Navbar.jsx — The Wrapper Component

The agent builds `Navbar.jsx` which configures PillNav for Infiniti Luxe's specific needs. This wrapper handles three things PillNav doesn't do natively:

**1. Scroll detection** — adds `pill-nav--scrolled` class on the container after 60px scroll

**2. Travel dropdown** — "Travel" is a nav item that triggers a dropdown. Since PillNav doesn't support this natively, the agent handles it by:
- Rendering "Travel" as a standard pill item in PillNav
- Positioning a custom `TravelDropdown` div directly below the PillNav container
- The dropdown appears on hover of the Travel pill — use a `hoveredItem` state that gets set on `onMouseEnter` of the Travel pill, cleared on `onMouseLeave` of both the pill and the dropdown itself

**3. WhatsApp CTA** — positioned absolutely to the right of the pill-nav-container, vertically aligned. It is **not** a PillNav item — it's a sibling element.

### Mobile Behavior (below 768px)

On mobile, the PillNav renders its hamburger button. The `Navbar.jsx` wrapper passes `onMobileMenuClick` to handle Travel dropdown expansion within the mobile menu.

The Travel dropdown items in mobile do not use the floating dropdown — instead, they appear as indented items within the PillNav mobile popover, revealed when "Travel" is tapped. The agent handles this by:
- Intercepting the Travel item click on mobile
- Toggling a `mobileDropdownOpen` state
- Conditionally rendering the 7 Travel sub-items as additional mobile menu entries with a `16px` left padding indent, a `3px` left border in `--color-gold`, and slightly smaller 14px font

WhatsApp button on mobile: rendered inside the PillNav mobile popover at the bottom, full-width, above the popover's bottom padding.
