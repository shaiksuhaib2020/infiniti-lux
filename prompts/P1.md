## PART 4 — ANIMATION INSTRUCTIONS

These apply across the homepage. Tell the agent:

**GSAP ScrollTrigger reveals** — Apply to every section as it enters the viewport:
- Default behavior: elements fade in (`opacity: 0 → 1`) and rise slightly (`y: 30 → 0`)
- Duration: 0.7s, ease: `power2.out`
- Stagger children (e.g., cards, trust points) by 0.1s so they reveal sequentially, not all at once

**Card hover** — All via CSS transitions, not GSAP. `transition: transform 0.25s ease, box-shadow 0.25s ease`

**Navbar scroll behavior** — CSS class toggle via JS scroll listener. Transition: `background 0.3s ease, backdrop-filter 0.3s ease`

**Respect `prefers-reduced-motion`** — If the user's OS has reduced motion on, skip all GSAP animations. The agent should wrap all GSAP calls with a check for `window.matchMedia('(prefers-reduced-motion: reduce)').matches`
