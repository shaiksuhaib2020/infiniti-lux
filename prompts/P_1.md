## FIX 3 — MODULE COUNT / BUNDLE BLOAT

2300–2420 modules on simple text pages means something heavy is loading globally. The agent audits in this order:

**A — Find where GSAP is imported:**

GSAP is likely imported at the top level of `Navbar.jsx` or in `layout.jsx`. Because `layout.jsx` wraps every page, any library imported there ships to every page — including `/visa-services`, `/about`, `/contact` which have minimal animation needs.

The agent checks every file in `/components/layout/` for top-level GSAP imports:

```js
import { gsap } from 'gsap';                    // ← ships to every page
import { ScrollTrigger } from 'gsap/ScrollTrigger'; // ← ships to every page
```

If found in `Navbar.jsx` or `layout.jsx`, move the GSAP import inside the `useEffect` that uses it:

```js
useEffect(() => {
  const { gsap } = await import('gsap');
  // use gsap here
}, []);
```

Or convert the navbar scroll behaviour to use `IntersectionObserver` instead of GSAP — a 0-dependency approach that is more appropriate for a simple scroll class toggle:

```js
useEffect(() => {
  const observer = new IntersectionObserver(
    ([entry]) => setIsScrolled(!entry.isIntersecting),
    { threshold: 0 }
  );
  // observe a sentinel element at the top of the page
}, []);
```

**B — Confirm `ogl` and CircularGallery are code-split:**

The `DestinationGallery.jsx` must use:
```js
const CircularGallery = dynamic(
  () => import('@/components/ui/CircularGallery'),
  { ssr: false }
);
```

If this `dynamic` import is missing and `CircularGallery` is imported statically, `ogl` (WebGL library) bundles into every page that imports `DestinationGallery`, which would add hundreds of modules to every route. Confirm the dynamic import is in place.

**C — Confirm GSAP ScrollTrigger is not registered globally:**

```js
gsap.registerPlugin(ScrollTrigger); // ← if this is in layout.jsx, it loads everywhere
```

This line should only exist inside the specific component files that use ScrollTrigger — `Hero.jsx`, `PinnedCards.jsx`, etc. Never in a layout or global file.
